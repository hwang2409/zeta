# Sink protocol and rollback

For each planned step, call `sink.apply(step.name, step.payload)`. Record a name
as completed only after that call returns. If `apply` raises, call
`sink.rollback(completed_names)` with the successfully completed names in
completion order, then re-raise the original exception. The sink owns any
reversal of that list.

For the example in `01.md`, a successful execution makes these calls:

```python
sink.apply("build", "")
sink.apply("ship", "image:v1")
```
