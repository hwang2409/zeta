# Input schema

`raw` is a mapping with a `steps` field whose value is a list. Each list item is
a mapping with these fields:

- `name`: required string.
- `dependencies`: optional list of strings; it defaults to `[]`.
- `payload`: optional value; it defaults to `""`, and every supplied value is
  coerced with `str(value)`.

For example:

```python
{
    "steps": [
        {"name": "ship", "dependencies": ["build"], "payload": "image:v1"},
        {"name": "build"},
    ]
}
```

Parse each item into a `Step`; preserve the listed dependencies as an immutable
tuple.
